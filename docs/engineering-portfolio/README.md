# Guy Eden Engineering Portfolio

Static, public-safe engineering portfolio.

## Preview

Open `index.html` in a browser.

## Publish

The folder can be published directly through GitHub Pages, Cloudflare Pages, or Netlify. No build step is required.

This directory is the publishable repository root. The sibling `portfolio-ssot` directory is private source material and must not be copied into the public repository.

## Confidentiality

All project pages are generalized reconstructions using synthetic names, code, data, and topology. Review employer policies before publication.
