Every project page includes the architecture at a glance, the concrete trade-offs made, an illustrative code example, and the questions I'd expect to get asked about it in an interview.

## Why the projects are "reconstructions"

The work is real; the names, data, and identifiers aren't. Each page is a generalized rebuild of something I actually built, with employer-specific details replaced by synthetic equivalents — so the architecture and reasoning are accurate while nothing confidential is exposed. Details on any project are available on request.
